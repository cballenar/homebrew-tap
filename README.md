# Homebrew Tap (`cballenar/tap`)

Official [Homebrew](https://brew.sh) tap for CLI tools by [@cballenar](https://github.com/cballenar).

## Installation

```bash
brew install cballenar/tap/arborist
```

Or tap first, then install:

```bash
brew tap cballenar/tap
brew install arborist
```

## Available Formulae

| Formula | Description |
| :--- | :--- |
| [`arborist`](https://github.com/cballenar/arborist) (`gar`) | High-performance Git worktree and isolated database manager for local web development (DDEV, Lando, Docker). |
